ACCOUNT HELP

Password help

Email recovery is not configured. You can securely reset the local account password from the project folder on this computer.

  1. Open PowerShell in the website project folder.
  2. Run .\scripts\reset-account-password.ps1.
  3. Enter your account email, then choose and confirm a new password. Password input stays hidden in the terminal.

The new password needs 12+ characters, uppercase and lowercase letters, a number, and a symbol. If the API uses a custom DATA_DIR, set the same value in this PowerShell window before running the script.
